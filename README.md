# Roblox VPN Guard

> 🛡️ Windows-приложение, которое контролирует запуск Roblox и не позволяет играть без запущенного Happ.

## 📌 О проекте

**Roblox VPN Guard** — небольшая Windows-утилита, написанная на Python, созданная для пользователей, которым необходимо использовать VPN при игре в Roblox.

Приложение проверяет, запущен ли **Happ**, и контролирует процесс Roblox.

Если Happ запущен — Roblox работает как обычно.

Если Happ не запущен, Roblox автоматически закрывается, а пользователь получает уведомление о необходимости запустить Happ.

> 💡 Использование VPN может влиять на определяемый Roblox регион, однако конечное поведение зависит от используемого VPN и самого Roblox.

## ⚙️ Как это работает

```text
              Запуск Roblox
                    │
                    ▼
            Проверка Happ
                    │
             ┌──────┴──────┐
             │             │
          Happ запущен   Happ не запущен
             │             │
             ▼             ▼
        Roblox работает   Roblox закрывается
                           │
                           ▼
                    Уведомление:
                   "Happ не запущен"
```

Приложение работает в фоновом режиме и отслеживает состояние процесса Roblox и Happ.

### Если Happ запущен

Roblox запускается и продолжает работать без вмешательства приложения.

### Если Happ не запущен

При запуске Roblox приложение обнаруживает, что Happ не работает:

1. Roblox закрывается.
2. Пользователь получает уведомление.
3. Пользователю необходимо запустить Happ.
4. После запуска Happ Roblox можно открыть снова.

## 📥 Установка

### Готовый `.exe`

1. Откройте раздел **Releases**.
2. Скачайте последнюю версию приложения.
3. Запустите `.exe`.
4. Убедитесь, что Happ установлен и настроен.
5. Запустите Roblox через обычный способ.

## 🔐 Почему Happ?

Приложение разработано с расчётом на использование **Happ** в качестве VPN-клиента.

Roblox VPN Guard самостоятельно не предоставляет VPN-соединение — он только проверяет наличие запущенного Happ перед использованием Roblox.
